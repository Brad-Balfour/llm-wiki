# Interface Design Rules

Interface heuristics can improve a design's baseline legibility and consistency
when they are used as prompts for judgment rather than substitutes for user
testing. They are especially useful for preventing common visual-hierarchy and
interaction mistakes early in implementation.

## Key Ideas

- Clear hierarchy, contrast, spacing, and predictable interaction affordances
  make an interface easier to scan and use.
- Rules are most useful when they explain the failure mode they are avoiding,
  so a designer can recognize when an exception is justified.
- Accessibility and real task completion remain stronger evidence than a
  checklist alone.
