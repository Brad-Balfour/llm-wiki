# Framefields

[Framefields](https://github.com/gatewai-dev/framefields) is a code-first video
SDK whose README describes TypeScript compositions, frame inspection, and MP4
rendering through Dawn/WebGPU/Metal/Vulkan rather than browser screenshots.
Its components include compositing, typography, keyframes, 3D scenes, audio,
animated charts, and vision helpers. FrameGrid contact sheets and live preview
support visual iteration.

The useful pattern is reproducible video as software with visual verification:
code makes a composition editable and repeatable; rendered frames remain the
acceptance evidence. The repository labels the SDK beta, warns that APIs are
unstable or incomplete, and provides Apache-2.0 licensing. No installation,
render, performance comparison, or production reliability test was performed.

The October 6 commute explicitly saved the project after confirming its name.
No additional user implementation decision or comparison with creative suites
is inferred from that save.
