# Nunebot Orchestration Prompt

[Open John Nunemaker's published Nunebot prompt](https://gist.github.com/jnunemaker/e421523d2508716450d41a5d785e48ce).
The Gist is a snapshot dated October 29, 2026. The instructions describe how
a coordinator loads ranked work and prior feedback, assigns repository work
to subagents and records outcomes for later runs. Workers isolate changes in
worktrees, keep PRs small and provide verification evidence. Human review
remains the merge boundary.

The commute requested the direct Gist as a standalone reference. For the
author's account of how he uses it, see the
[Nunebot maintenance workflow](../concepts/nunebot-maintenance-workflow.html).
