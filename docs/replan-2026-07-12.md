# Replan After Manual ChatGPT Voice Proof Of Concept

Date: 2026-07-12

## New Evidence

The manual workflow has now proven that ChatGPT Projects, the Gmail connector,
Library files, and Voice can cover the product loop far enough to test it in a
real car:

1. Project source files hold the classifier prompt, interest profile, queue
   contract, and reader instructions.
2. A project chat uses the Gmail connector to read and classify one TLDR
   newsletter.
3. ChatGPT creates the ordered queue as JSON content in a `.txt` file and stores
   it in the Library folder named `LLM-Wiki-Car`, matching the ChatGPT Project.
4. A fresh project chat loads that queue before driving and Voice reads it.

This validates the manual car MVP earlier than the implementation plan expected.
It does not yet validate deterministic repo ingestion, classification quality at
scale, durable feedback capture, or wiki compilation.

The first two-trip prototype also showed that Voice will not provide a verbatim
audio performance of linked article text. The car workflow should retrieve
linked material when available and provide grounded summaries and discussion,
not claim to read the article aloud. It also showed that wiki-marked handoff
notes still need a reviewed promotion adapter before they become
`approved-wiki-source.v1` compiler inputs.

Reviewing the original newsletter, the in-depth queue data, and the completed
handoff exposed a separate identity bug. The June 23 source email was TLDR AI,
although the manually created queue labeled it TLDR Dev. The queue/handoff also
replaced stable source item ids with invented sequential ids. Finally, a general
interest in automated testing tools was incorrectly emitted as an article-level
wiki review record even though no matching newsletter article, source id, or URL
existed. The project instructions now require exact id/title/URL copying from
the current queue item and route unmatched topic preferences to general review.
The recovered handoff uses the stable ids `tldr_79edd44693b74006` for the LLM
architecture item and `tldr_f6b2ae0fb7b44ced` for the Extended Thinking item.
